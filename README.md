# RaktSetu – Blood Bank Finder

RaktSetu is a demo website that helps users search sample blood bank listings by blood group and city.

## Features
- Search by blood group
- Search by city
- View matching blood bank cards
- Clear search fields
- Backend API using Node.js and Express

## Technologies
- HTML
- CSS
- JavaScript
- Node.js
- Express

## Run the Project
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run: node server.js
4. Open http://localhost:3000 in your browser.

## Important
This project uses sample demo data. Blood bank names, units, and contact details are not verified live availability. Confirm information with an authorized blood bank.
